# design-critique

Evaluates interfaces against high UX standards (heuristics, UX laws, cognitive psychology, UI fundamentals) and delivers actionable design improvements.

**Use when:** the user asks for a design critique, UX review, interface evaluation, or heuristic evaluation.

## Installation

With the [skills](https://github.com/vercel-labs/skills) CLI (Cursor, Cline, Windsurf, and other agents):

```bash
npx skills add uxdudu/design-critique
```

Or with a direct link to this skill:

```bash
npx skills add https://github.com/uxdudu/design-critique/tree/main/design-critique
```

## What it covers

- **Nielsen's usability heuristics** — visibility of status, consistency, error prevention, etc.
- **UX laws** — Hick's Law, Fitts's Law, Jakob's Law, and others
- **Cognitive psychology** — cognitive load, attention, working memory
- **Gestalt & visual design** — alignment, proximity, contrast, spacing, proportion
- **Typographic proportion** — scale, hierarchy, rhythm
- **Interactive affordances** — buttons, links, states (hover, focus, disabled)
- **Accessibility** — keyboard, focus, labels, semantics

The skill is technology-agnostic and does not prescribe a specific framework or design system.
